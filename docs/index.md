# AIVO RMS

Платформа управления рестораном: цифровое меню с заказом со стола, POS для
официантов, админ-панель с AI-ассистентом. Ресторан регистрируется сам,
получает свой адрес (`/{slug}` или собственный домен) и настраивает меню
под свой бренд.

## Кому что

- **[Ресторану](user/owner.md)** — регистрация, меню, темы, QR-столы, подписка, CRM гостей.
- **[Официанту](user/waiter.md)** — смены, тикеты, приём заказа по коду.
- **[Разработчикам](dev/setup.md)** — запуск, архитектура, API.

## Как это устроено

Гость сканирует QR на столе → открывает меню ресторана → собирает корзину →
показывает код официанту. Официант принимает код в POS — позиции падают в
тикет стола. В конце смены касса сводится автоматически.
