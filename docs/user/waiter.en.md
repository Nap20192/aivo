# For waiters

Your working screen is `/pos` on your phone. The manager gives you your
login and password.

## Shift

- **Open shift**: enter the opening float in the till. No tickets can be
  created until a shift is open.
- **Close shift**: enter the counted cash — the system computes the
  expected amount (float + sales) and the variance. A closed shift is
  immutable.

## Tickets

- One open ticket per table. It opens when the first items are added;
  further items go onto the same ticket.
- **Fire** sends items to the kitchen (stamps the time).
- Closing a ticket locks the total; a closed ticket cannot be changed.

## Order by code (handoff)

A guest builds a cart in the menu and shows you a 6-character code (or QR).

1. In the POS: **"Accept code"** → type the code.
2. Review the item preview and the guest's note → confirm.
3. The items land on the table's ticket; the note is kept on the ticket.

Codes are single-use and live for 15 minutes. If the guest is logged in,
the order counts toward the CRM.

## Table requests

The requests tab shows "call waiter" and "bill" requests from tables.
Acknowledge one — it disappears on the guest's screen.
